# Skill :: estetica Desfile de Faroles

Aplica el sistema de `DESIGN.md`. Reglas duras que no se rompen:

1. Sin emojis en UI, codigo ni texto.
2. Sin em dashes (`-`). Usar `-`, `:`, `::`, `|`.
3. Sin franja de color en el borde izquierdo: colorear el elemento completo, uniforme.
4. Paleta Costa Rica: night `#0a1230`, ink `#f4f4f4`, blue `#0b4da2`, red `#ce1126`, gold `#ffb703`.
5. Sin iconos de libreria (nada de Lucide): SVG propios inline.
6. Evitar el look generico de "SaaS moderno": glassmorphism liquido, gradientes agresivos,
   neon, purpura+negro, bento grids, tres tarjetas en fila, sparkles, dot grids de relleno.

Preferir: decisiones visuales con personalidad, jerarquia intencional, contenido
autentico, movimiento con proposito, sistema coherente. Fuente base `system-ui`
(no Inter/Geist/Space Grotesk).

Ver `DESIGN.md` para tokens, tipografia, componentes y guia completa.
